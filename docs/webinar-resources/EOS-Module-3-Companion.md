## 1. Diagnostic Checklist

Use with leadership or alone. Prefer facts over aspirations. Complete in the **guided checklist** (Yes / Partially / No + short note). No essay required.

### Scorecard as the weekly truth system
- [ ] The Scorecard is reviewed in Level 10 and actually triggers IDS — not only archived after the meeting.
- [ ] Metrics are few and owned by people who can change the number (operators), not only by Finance or HR as spectators.

### Locked capacity metrics (this module’s core)
- [ ] For a **named critical seat family**, the **live Scorecard** includes these metrics **verbatim**:  
  1. pipeline health for a named critical seat family  
  2. retention of institutional knowledge in critical seats  
  3. share of critical seats held by long-term American workers  
- [ ] Each of those has an **operator owner** named on the Scorecard.
- [ ] Leadership accepts that a **green cost/fill** line does **not** equal success when any of the three capacity metrics is red or missing.

### Failure mode (what bad metrics incentivize)
- [ ] **Failure mode check:** The Scorecard does not treat cheap fill-rate or headcount speed as a win when critical seats remain on permanent short-cycle temporary or visa labor design.
- [ ] We can point to one recent period where cost looked fine and capacity was already slipping.

### One-line hand-offs
- [ ] At least one capacity metric is (or will be) tied to a Rock — Rocks system is Module 2; this companion only requires the link, not a Rocks redesign.
- [ ] The named seat family matches the People design choice in Module 5.

### Anchors
- [ ] Team can state: we either score strength that compounds or we score cost that can hide weakness.
- [ ] **Posture:** Operating in the United States is not workforce-neutral. Seat design either builds lasting productive capacity or rents weakness.

**Diagnostic result (one line):**  
Biggest gap — missing locked metrics on the live Scorecard, no operator owners, green cost hiding red capacity, or Level 10 that never IDS’s the Scorecard gap?

## 2. 90-Day Outline (Free Execution Scaffold)

This is a **starting outline**, not a full managed engagement. Paid implementation support (e.g. 90-Day Sovereign Capacity Sprint) sits behind deeper facilitation and cross-module integration.

### Days 1–30 — Diagnose
| Action | Output |
|--------|--------|
| Review live Scorecard; separate cost/fill lines from capacity lines | Annotated Scorecard |
| Check for the three locked capacity metrics on one named seat family | Present / missing / owner |
| Note where green cost coexists with weak or absent capacity metrics | Gap list |
| Confirm operator owners (not spectators) | Owner map |

### Days 31–60 — Redesign
| Action | Output |
|--------|--------|
| Put the three locked capacity metrics (verbatim) on the live Scorecard for one seat family | Metrics live |
| Name operator owners on the Scorecard | Owners visible |
| One-line link to a Rock (Module 2) and seat family (Module 5) | Link note only |

### Days 61–90 — Execute & Embed
| Action | Output |
|--------|--------|
| Level 10 IDS when a capacity metric is red and cost is still green | At least one documented IDS |
| Keep the capacity metrics on the Scorecard next quarter | Locked set |
| No further Rocks or seat redesign in this companion — hand off | Hand-off list |

**Success check at day 90:**  
The three locked capacity metrics are live with operator owners for a named seat family; green cost is no longer treated as success when capacity is red; Level 10 has IDS’d a Scorecard capacity gap at least once — **so the Scorecard measures lasting productive capacity rather than rents weakness.**

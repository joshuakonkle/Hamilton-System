## 1. Diagnostic Checklist

Use with leadership or alone. Prefer facts over aspirations. Complete in the **guided checklist** (Yes / Partially / No + short note). No essay required.

### Core Focus & productive picture
- [ ] Core Focus names **what we build or strengthen** (productive capacity), not only who we sell to or how we cut cost.
- [ ] The 10-Year Target / 3-Year Picture describes **capability that compounds** (skills, process, domestic strength), not only revenue or headcount.
- [ ] Leadership can state in one sentence how the Vision **reduces dependence on short-cycle temporary or visa labor** over time — or admits it does not yet.

### Marketing Strategy & differentiator
- [ ] Differentiator is grounded in **capability or reliability** others cannot rent cheaply (process, knowledge, delivery), not only price or speed-to-fill.
- [ ] Target market assumptions do not depend on permanent short-cycle temporary or visa labor coverage as the operating model.

### 1-Year Plan, Rocks & issues
- [ ] At least one annual priority or Rock is explicitly tied to **building capacity** (pipeline, knowledge retention, critical seat strength) — not only fill-rate or cost.
- [ ] Issues list includes capacity or knowledge risks when cost still looks fine.

### Failure mode (Vision-level)
- [ ] **Failure mode check:** If the V/TO still assumes critical capacity will be met by permanent short-cycle temporary or visa labor design, that assumption is named as a **Vision risk**, not left implicit.

### Anchors (shared language)
- [ ] Team can state how Vision feeds Rocks (Module 2), Scorecard (Module 3), Process (Module 4), and People (Module 5) without treating people as a pure cost line.
- [ ] **Posture:** Operating in the United States is not workforce-neutral. Seat design either builds lasting productive capacity or rents weakness.

**Diagnostic result (one line):**  
Where is the gap — Core Focus that only cuts cost, Picture that ignores capacity, Rocks with no capacity link, or an implicit permanent short-cycle temporary or visa labor assumption treated as a Vision risk?

## 2. 90-Day Outline (Free Execution Scaffold)

This is a **starting outline**, not a full managed engagement. Paid implementation support (e.g. 90-Day Sovereign Capacity Sprint) sits behind deeper facilitation and cross-module integration.

### Days 1–30 — Diagnose
| Action | Output |
|--------|--------|
| Review Core Focus, 10-Year Target, 3-Year Picture for productive vs. pure cost language | Marked V/TO pages + gap notes |
| Test whether Vision reduces dependence on short-cycle temporary or visa labor over time | One written sentence (yes / not yet + why) |
| **Failure mode:** Name any implicit permanent short-cycle temporary or visa labor assumption for critical capacity | Explicit Vision-risk note |
| List current Rocks; tag which (if any) build capacity | Rock list with capacity tag |

### Days 31–60 — Redesign
| Action | Output |
|--------|--------|
| Tighten Core Focus or 3-Year Picture so capacity compounds (not only revenue) | Revised language for leadership sign-off |
| Add or rewrite **one** Rock tied to a capacity outcome (pipeline, knowledge, critical seat) | Rock statement + owner |
| Align that Rock to a future Scorecard capacity metric (Module 3 hand-off) | Metric name + owner placeholder |

### Days 61–90 — Execute & Embed
| Action | Output |
|--------|--------|
| Run Vision/Rocks review in Level 10 with capacity on the table when cost is green | Documented discussion or IDS |
| Lock the capacity-linked Rock into the next quarter | Updated 1-Year Plan / Rocks |
| Hand off: Rocks system (M2) · Scorecard metrics (M3) · seat design (M5) | One-line hand-off list |

**Success check at day 90:**  
Vision language names productive capacity (not only cost); at least one Rock is capacity-linked; any permanent short-cycle temporary or visa labor assumption for critical capacity is explicit as a **Vision risk** — **so the picture builds lasting productive capacity rather than rents weakness.**
